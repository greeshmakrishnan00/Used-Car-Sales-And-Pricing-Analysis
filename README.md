# 🚗 Used Car Market Intelligence & Price Analysis

### A Data Analytics Project Using Python, EDA & Power BI

---

## 📌 Project Overview

The used car market is influenced by various factors such as vehicle brand, manufacturing year, kilometers driven, fuel type, transmission, engine specifications, and ownership history.

This project analyzes the Car Dekho used car dataset to understand vehicle pricing patterns, resale value trends, and the relationship between vehicle characteristics and selling prices.

Using Python for data cleaning and Exploratory Data Analysis (EDA), along with Power BI for interactive visualization, this project transforms raw vehicle data into meaningful insights about the used car market.

## 🎯 Project Objectives

- Analyze used car selling prices across different brands, models, and manufacturing years.
- Explore the relationship between vehicle age, kilometers driven, and resale value.
- Compare pricing patterns across fuel types, transmission systems, and seller categories.
- Understand how ownership history relates to vehicle pricing.
- Analyze mileage efficiency, engine capacity, and vehicle performance.
- Identify high-priced vehicles despite extensive usage.
- Develop an interactive Power BI dashboard to present key insights.

## 📂 Dataset Overview

The dataset contains approximately 6,928 vehicle records and 18 attributes covering vehicle specifications, pricing, and usage characteristics.

## 🔍 Key Findings

- Vehicle age has a negative correlation of approximately -0.44 with selling price.
- Kilometers driven has a negative correlation of approximately -0.17 with selling price.
- Diesel vehicles represent the largest fuel category in the dataset.
- Automatic vehicles have a higher average selling price than manual vehicles.
- Dealer-listed vehicles have a higher average selling price than individual seller listings.
- First-owner vehicles generally show higher average selling prices than vehicles with multiple previous owners.
- Some vehicles maintain relatively high selling prices despite extensive usage.

*These findings represent patterns and associations observed in the dataset and do not establish direct cause-and-effect relationships.*
